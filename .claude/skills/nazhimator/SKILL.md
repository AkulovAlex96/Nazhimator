# Nazhimator

## Подключение (один раз)

1. Порт платы сервер находит сам (VID Espressif); `SERIAL_PORT` нужен, только если подключено несколько ESP.
2. Зарегистрировать сервер из `server/`:
   ```
   claude mcp add nazhimator -e CAMERA_SOURCE=<0|URL|adb> [-e CROP=x,y,w,h] -- $PWD/.venv/bin/python $PWD/mcp_server.py
   ```
3. Перезапустить сессию, проверить `/mcp`.

Порт одновременно держит один процесс: `server/console.py` (ручная консоль) и MCP-сервер вместе не работают.

## Управление

Инструменты MCP:
- `screenshot`: снимок экрана. Начинай с него, чтобы понять текущее состояние.
- `press(button, ms=100)`: `esc` | `up` | `down` | `enter`, до 3000 мс.
- `press_and_look(button, ms)`: нажать и сразу получить снимок. Основной инструмент.
- `release_all`: отпустить всё (если что-то зависло).

Правила:
- Одно нажатие, затем проверка экрана. Не делай серий вслепую.
- Если нажатие не сработало, увеличь `ms` (200–500): устройство может опрашивать кнопки редко.
- Деструктивные пункты меню (сброс, форматирование, прошивка) подтверждай у пользователя перед `enter`.
- `enter` на неясном экране не нажимай: сначала `screenshot`.

## Диагностика

- Нет ответа от платы: плата не найдена, порт занят или нет прав (`sudo usermod -aG dialout $USER`).
- Кадр мутный или не тот: `server/camera_setup.py live` / `crop`, затем обновить `CROP`.
- Ручная проверка без ИИ: `server/.venv/bin/python server/console.py` (стрелки, Enter, Esc).
